## F HamLog 2 Inno Setup 安装包 file 目录保留策略调整
- 需求（日常开发场景）：file 目录"存在则保留、不存在则创建（带数据）"，其他程序文件全部覆盖。
- 原 .iss 用目录级判断 `Check: not DirExists('{app}\file')` 复制 `main.dist\file\*`，缺陷：目标 file 目录存在但模板缺失/被删时不会补回。
- 改为单文件级 `onlyifdoesntexist`：把 file 目录下 8 个顶层文件（amateur.tle、F_HamLog.ico、main.fhl、m_xml.txt、pack_list.txt、sat_radio_dict.txt、tqsl_dict.txt、world_land.json）逐条列出，每个加 `Flags: onlyifdoesntexist`（不可与 `*` 通配符 / `recursesubdirs` 共用）。
- 普通程序文件仍用 `ignoreversion` 覆盖；`[Dirs]` 建 file 目录逻辑保留（冗余无害）。
- 本机未安装 ISCC，未做编译校验；如需验证需先安装 Inno Setup 6。
