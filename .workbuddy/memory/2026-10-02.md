## 悬浮提示宽度自适应（toast_tip.py，@scene#15 日常开发）
- 需求：宽度随文案自适应——**需要的宽度 < 当前宽度 → 保持当前宽度（不缩窄）；更大 → 加宽**。
- 旧实现的两个问题：`w = min(max(label.width()+22, 96), 440)`，而 `label.width()` 在 `wordWrap=True` 下
  会给出**折行后**的宽度 → 长文案（如"没有可删除的日志：请先在…"需 456px）被折成 274 宽 2 行，**没有加宽**；
  且高度用折行前的 `label.height()`，与实际排版不一致（幸好当时高度也取自折行后尺寸才没错版）。
- 新实现（`toast_tip.py`）：
  ```python
  fm = QFontMetrics(label.font())
  need_w = fm.horizontalAdvance(text) + _PAD_X*2 + _SLACK_X   # 单行完整显示所需
  w = min(max(need_w, _MIN_W), _max_toast_width())            # 不小于当前口径；需要更宽就加宽
  h = label.heightForWidth(w) + _H_EXTRA                      # 按最终宽度重排后取真实高度
  ```
- 新增常量区（改宽度只需改这里）：`_PAD_X=12`/`_PAD_Y=6`（与 QSS padding 一致）、`_SLACK_X=22`（沿用余量）、
  `_MIN_W=96`、`_MAX_W=440`、`_MAX_RATIO=0.8`、`_MAX_ABS=900`（上限 = clamp(屏幕宽×0.8, 440, 900)，超过才折行）、
  `_H_EXTRA=12`；`_label_css(fg)` 收敛了原先两处重复的 QSS 字符串。
- **实测（`test/__toast_width_probe.py`，离屏 800px 屏）**：短/中文案宽度与旧版**逐项一致**（118/166/214/226/154/238…），
  仅长文案由 274×50（2 行）变为 **502×36（单行）**；超长文案收敛到上限 640 后折行、高度增长。
- **关键 API 结论**：`QLabel.heightForWidth(w)` 返回的高度**包含 QSS padding**（单行 24 = 文字 12 + 上下 12），
  是"给定宽度下 label 真实高度"的可靠算法；`QFontMetrics.horizontalAdvance(text)` 是单行文字的精确宽度。
- 验证：`test/__toast_smoke.py` 扩到 **18 项断言**（新增 7.1 短文案保持口径 / 7.2 长文案加宽且单行 / 7.3 超长折行不截断），
  18/18 通过；`__perf_func_smoke.py` 15/15 无回归。另生成目视拼图 `__toast_width_out.png`（已 gitignore）。
