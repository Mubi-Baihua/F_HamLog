# 2026-11-15

## 1. 修复「打开多个项目时不同日志串在一起」

**根因**：`project.py` 的 `file` / `key` 是**模块全局**，而 `main()` 里所有闭包
（save / table_update / undo / import / append_to_project / `_on_sync` / 插件 handler）
读的都是它们。打开第二个项目时 `file` 被覆盖成新项目的列表 → 第一个窗口的保存、
追加、批量记录落盘全部作用到**后一个项目**上。旧 `main.py` 只保留一个
`project_window` 引用，但窗口因闭包循环引用并未真被回收，所以两个窗口能同时活着。

**改法**：
- `file` / `key` / `project_others_window` / `custom_fields_window` / `research_window`
  全部改成 `main()` 的局部变量，闭包用 `nonlocal`；换列表统一走 `_set_file()`、
  换密钥走 `_set_key()`。模块级同名变量只留「最近一个窗口」的**镜像**（写入
  `globals()['file'|'key'|…]`），仅供 `tests/__*.py` 观察，逻辑内部不再读。
- 窗口上另存权威引用：`window._file` / `window._key` / `window._others_window` /
  `window._custom_fields_window`。
- `main.py`：新增 `project_windows` 全量列表 + `_new_project_window()`，
  打开新项目**不再关掉**旧项目；`_confirm_replace_session()` 因此退化为恒 True
  （函数名保留，调用点不动）。
- 未保存备份改为**按项目文件路径分开**：`backup.project_backup_path(save_path)`
  → `file/project_backup_<sha1前12位>.fhl`（未落盘的项目仍用公共 `PROJECT_BACKUP`）；
  `backup.list_project_backups()` 供启动时逐个恢复，不再只恢复「最后写备份的那个」。
- `append_to_project` 增加判活：原项目窗口已关闭时抛错，让批量记录退回「完成」页。
- 修掉一个隐蔽点：插件 `handler()` 里的 `file = new_recs` 在 key/file 变局部后
  会创建**函数局部变量**（表格读不到新内容）→ 改 `_set_file(new_recs)`。

**验证**：`tests/__multiproject_adi_smoke.py` M1–M8；`__fhla_smoke` 173/173；
`__inplace_edit_smoke` 22/22；`__scroll_restore_smoke` 15/15；`__pack_fhla_smoke` 20/20。

## 3. 直接打开 / 编辑 / 保存 .adi

- `project.is_adi_path()`（认 `.adi` / `.adif`）；`read_project_file` / `save_project_file`
  按扩展名分派到 `read_adi_file()` / `write_adi_file()`。
- 解析与生成**复用现有实现**：`input_adi.read_adi_records()`（UTC→本地、字段映射）
  与 `export_adi.write_adif_file()`（本地→UTC、BAND 推导）。导入/导出/直接打开三处
  行为永远一致。
- 过滤器：`OPEN_FILTER_BOTH` 加 `*.adi`；`project_save_filters()` 追加第三条
  `ADI 日志 (*.adi)`（第一条仍是 `.fhla`）；`complete_project_suffix` 支持补 `.adi`。
- `.adi` 无属性块、无加密 → 「项目属性」提示「ADI 是通用日志交换格式…」，
  不显示「加密此项目」菜单。
- **打开后没改动就不写盘**（`save(message=False)` 里加特判）：ADIF 重写会把标签重排
  并丢掉未映射标签（QSL_SENT 等），「打开即自动保存」在 .adi 上是破坏性动作。
- i18n 新增词条：`自动保存到日志文件` / `（{}）` / `请选择要保存到的日志` /
  `ADI 日志 (*.adi)` / 合并打开过滤器 / ADI 属性提示。

**验证**：`tests/__multiproject_adi_smoke.py` D1–D14（含 D4b 不重写断言）。
