### 关键坑：Windows 上「探测端口是否被占用」的正确写法
排查过程逐层否决了三种错误做法，最终结论（已写进代码注释与 MEMORY.md）：

1. **connect 探测不可用**：`settimeout()` 后 `connect_ex` 对**空闲**端口返回
   `WSAEWOULDBLOCK(10035)`，与占用无法区分（占用实测返回 0）。
2. **探测 socket 绝不能设 `SO_REUSEADDR`**：Windows 允许在已设置 `SO_REUSEADDR` 的情况下
   bind 到**同一地址已监听的端口**，导致探测恒判「空闲」。实测：
   holder 在 127.0.0.1 时，probe 127.0.0.1 + reuse=True → bind **成功**（漏判）；
   reuse=False → `FAIL(10048)`（正确）。
3. **Windows 绑定语义不对称，必须试探完全相同的地址**：
   - holder `127.0.0.1` → probe `127.0.0.1` FAIL / probe `0.0.0.0` **OK（漏判）**
   - holder `0.0.0.0`   → probe `0.0.0.0` FAIL / probe `127.0.0.1` **OK（漏判）**

   本项目服务端一律以 `0.0.0.0` 监听，故探测口径就是 `0.0.0.0`（`host` 为空/`::` 时归一为 `0.0.0.0`）。

最终实现（bind 探测、不设 SO_REUSEADDR、按同地址）：
```python
def _can_bind(host, port):        # True=可绑定(空闲)
    s = socket.socket(...)        # 注意：不要 setsockopt SO_REUSEADDR
    try: s.bind((host, int(port))); return True
    except OSError: return False
    finally: s.close()

def is_port_in_use(host, port):
    if not port: return False
    bind_host = host if host and host != '::' else '0.0.0.0'
    return not _can_bind(bind_host, port)
```

## 长期密钥存放位置分离：内嵌→file/、独立→自己目录

用户需求：「直接存到 file 中。服务端存到自己的文件夹」。此前内嵌服务端（「开放多人日志」）
把密钥放在 `file/remote_rooms/keys/`（跟着 fhl_path 走），现明确分离：

| 场景 | 密钥位置 | 由谁指定 |
|---|---|---|
| 内嵌服务端（客户端开房） | `file/keys/server_<端口>.fhlkey` | `project._open_lan()` 传 `key_dir='file'` |
| 独立服务端（`F_HamLog_Remote_Log_Server_2.0.0`） | `<程序目录>/keys/server_<端口>.fhlkey` | `main.py` 传 `key_dir=_app_dir()` |

### 改动
- `remote_server.py`：
  - `_data_dir(fhl_path=None, key_dir=None)` 新增 `key_dir` 形参，优先级
    **显式 key_dir > 日志文件所在目录 > cwd**。
  - `LogServer.__init__` 新增 `key_dir=None` 形参与 `self.key_dir`；`_load_keys` 与
    `_reload_keys_for_port` 统一改为 `_data_dir(self.fhl_path, self.key_dir)`。
- `project.py`：`_open_lan()` 两次 `LogServer(...)`（8000 尝试 + `port=0` 回退）均传 `key_dir='file'`。
- 独立服务端 `main.py`：`LogServer(...)` 显式传 `key_dir=_app_dir()`（此前依赖默认行为，
  虽已等价但语义不明确；现已写明并加注释强调两套密钥相互独立、换端口即换身份）。
- 独立服务端 `remote_server.py` 同步（两份 md5 一致：`c4ccb34c692c508001f4073fa1091ebf`）。
- `.gitignore`：新增 `file/keys/`、`F_HamLog_Remote_Log_Server_2.0.0/keys/`、`file/_key_backup_*/`。
