# 2026-07-26 工作日志

## 项目背景
F HamLog 是 PySide6 桌面业余无线电通联日志应用。核心源码在根目录：
- `main.py` 入口窗口
- `project.py` 主页面（日志表格、搜索、统计、导入导出、插件）
- 数据结构：`file` 为记录 list，每条 dict（date/time/m_call/o_call/freq/mode/prop_mode/sat_name/m_rst/o_rst/m_qth/o_qth/... notes）
- FHL 文件为 utf-8 JSON，读写走 `fhl_rw.py`（支持 AES 加密）
