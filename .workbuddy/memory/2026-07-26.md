# 2026-07-26 工作日志

## 项目背景
F HamLog 是 PySide6 桌面业余无线电通联日志应用。核心源码在根目录：
- `main.py` 入口窗口
- `project.py` 主页面（日志表格、搜索、统计、导入导出、插件）
- 数据结构：`file` 为记录 list，每条 dict（date/time/m_call/o_call/freq/mode/prop_mode/sat_name/m_rst/o_rst/m_qth/o_qth/... notes）
- FHL 文件为 utf-8 JSON，读写走 `fhl_rw.py`（支持 AES 加密）

## 本次改动：新增“预测业余卫星过境 + 卫星日志快速记录”功能

新增两个模块：
- `satellite_pred.py`：纯 Python（无第三方依赖）的 SGP4 传播（Vallado 标准实现 WGS72 转写，已与 upstream `sgp4` 库数值比对：LEO 误差<1km、GEO<0.01km）+ 观测站地平坐标换算（ECI→ECEF→SEZ）+ 过境预测（`predict_passes`）+ Celestrak 业余卫星 TLE 下载/缓存（`file/amateur.tle`）。内含 `SATE_BANDS` 常见卫星频段表用于快速记录预填。
- `satellite_window.py`：PySide6 预测窗口（940×620）。菜单/工具栏：刷新TLE、观测站设置、预测时长、最小仰角、全部/常用FM筛选；表格每行列含“记录”按钮，回调 `quick_log_callback(preset)` 打开预填的新建日志。首次打开若未设观测站则引导设置。

集成点：
1. `set.py`：设置新增观测站 纬度/经度/海拔（写入 `file/m_xml.txt` 的 `m_lat/m_lon/m_alt` 键，全部用 `.get` 读取避免 KeyError）。窗口固定尺寸 650×400→650×580。
2. `project.py`：`new(preset=None)` 支持预填（sat_name/prop_mode/date/time/freq/freq_rx/mode 等）；新增“卫星”菜单 → “卫星过境预测”（Ctrl+Shift+W），`quick_log` 回调调用 `new(preset)`。
3. `main.py`：主页新增“卫星过境”按钮，打开预测窗口（read-only，callback=None）。

注意：`satellite_window.main` 创建局部 `QMainWindow`，已在模块级 `_open_windows` 列表保存引用防止被 GC。PySide6 沙箱内不可用，仅 `py_compile` 校验 + `satellite_pred` 运行时冒烟测试（ISS 武汉观测 24h 16 次过境，符合预期）。
