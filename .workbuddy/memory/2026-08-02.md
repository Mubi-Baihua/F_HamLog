## 新增功能 1：卫星过境预测时长上限 24/72h → 240h
- `satellite_pred.py` 新增 `MAX_PREDICT_HOURS = 240` / `MIN_PREDICT_HOURS = 1` / `clamp_predict_hours(hours, default=24.0)`
  （非法输入回退 default，>240 一律收敛为 240，<1 提升为 1）。

## 新增功能 2：「通联预测」（双站卫星互视）
- 算法（`satellite_pred.py`）：
  - `visibility_windows(satrec, observer, start_utc, hours, min_elevation_deg)`
    —— 用 `find_events(..., altitude_degrees=min_elev)` 直接以**用户最低仰角**为门限求
    连续可见窗口，返回 `{'start_tt','end_tt','clipped_start','clipped_end'}`（TT 儒略日，便于求交）。
    处理了区间起点已在门限之上（先 set 后 rise）与终点仍在门限之上两种截断情形。
  - `predict_mutual_passes(satrec, obs_a, obs_b, start_utc, hours, min_elev_a, min_elev_b, min_duration_sec=10, samples=48)`
    —— 双指针求两站窗口交集；交集内 `np.linspace` 采样 48 点，`ts.tt_jd(数组)` 矢量化算 altaz，
    得两站最大仰角、首尾方位、以及"最佳时刻"（`np.minimum(ea, eb)` 的 argmax，即两站仰角较低者最高的时刻）。
  - `great_circle_km(lat1, lon1, lat2, lon2)` —— 两台站地面大圆距离。
- 界面 `mutual_window.py`（新建）：
  - `StationBox` 组件：纬/经/海拔 + 梅登黑格网格双向互转（网格→坐标 / 坐标→网格）+ 每站独立「最低仰角」。
    台站 A 默认取设置里的 `m_lat/m_lon/m_alt`（本站），台站 B 取上次填的 `sat_b_*`。
  - 预测参数：开始时间、时长(1–240)、范围(全部/自选卫星)、刷新TLE、开始预测（显式按钮，避免重算风暴）。
  - `MutualWorker(QThread)` 后台算，进度回报；结果表：卫星/可通联开始/结束/时长/A最大仰角/B最大仰角/最佳时刻/记录。
    窗口被区间边界截断时开始时间后缀「（截断）」。
  - 每行「记录」→ `quick_log_callback(preset)`，预填 sat_name(TQSL 名)/prop_mode=SAT/date/time/收发频率/模式/
    **o_qth = B 站网格**。
  - 新增持久化键：`sat_b_lat/sat_b_lon/sat_b_alt`、`sat_mu_el_a/sat_mu_el_b`、`sat_mu_dur`、
    `sat_mu_filter`、`sat_mu_sats`。
- `batch_project.py`：preset 白名单从 7 个键扩到 11 个，新增 `m_qth/o_qth/o_call/notes`（向后兼容）。
- 入口：`project.py`「卫星」菜单加「通联预测」(Ctrl+Shift+E)；`main.py` 主页把「卫星过境」由跨两列改为
  单列并新增「通联预测」按钮（窗口仍固定 575×375，未变高）。`main.py` 顺带把 `_quick_log` 提到
  `main()` 层复用，供两个卫星窗口共用。
