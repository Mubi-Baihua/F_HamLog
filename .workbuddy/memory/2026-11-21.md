## 新增 `src/f_hamlog_installer`（独立安装器 · Qt + CLI）
- 目的：用主程序「自动更新」那条链路（`check_update.download` / `run_installer`）装最新版，
  并把 GitHub Releases 上所有版本收到 `<out>/<版本>/<文件名>`；自带 GitHub 加速。
- 模块：`config.py`（仓库/目录/环境变量）、`github.py`（api.github.com 直连→镜像→JSON 缓存）、
  `releases.py`（版本排序、资源判定）、`download.py`（计划/跳过/manifest/换路重试）、
  `install.py`（exe→run_installer，msi→msiexec）、`cli.py`、`gui.py`、`__main__.py`（无参开界面）。
- `check_update.py` 只加了可选参数 `prefer='auto'|'direct'|'mirror'`（`choose_source` 与 `download`），
  默认行为、主程序调用不变。
- **资源判定**：1.x 的 `setup.exe` 只有 550 KB（联网下载器的壳）→ 自动改挑同版本的 msi；
  名字带 `remote`/`server` 的一律排除；`.zip` 是便携版，默认不下。
- **加速兜底**：`check_update` 的测速窗口只有 2 秒且含建连时间，绕代理时会把能用的镜像判成 0 分；
  安装器在下载层加「换路重试」——auto 先交给引擎，失败再逐个镜像（`--mirror on` 先 6 秒探活），直连垫底；
  下完核对字节数，镜像来源再抽样比对官方字节（官方不通就跳过比对，省 30 秒等待）。
- 目录：默认 `%LOCALAPPDATA%/F_HamLog/releases` + `manifest.json`（大小/sha256/来源/时间）；
  缓存 `%LOCALAPPDATA%/F_HamLog/installer/{cache,gui.json}`；env：`F_HAMLOG_RELEASES_DIR`、
  `F_HAMLOG_INSTALLER_CACHE`、`GITHUB_TOKEN`。
- 界面：版本表 + 关于页（反馈邮箱 / 更新页 / GitHub / 版本 / Coded by BI8SQL，与主程序设置页同一套文案；
  **不渲染 README**）。链接色取 `QPalette.Link`，深浅色实测都正常；表格末列按剩余宽度填满，无横向滚动条。

## 「无法正常安装」的两个真凶（重要）
1. **Inno 的 `/LOG=` 不吃引号**：`subprocess` 给含空格参数自动加引号 →
   Inno 把引号当文件名一部分 → 弹「Error creating log file: 文件名、目录名或卷标语法不正确」
   并中止安装。**结论：不要加 /LOG**（路径无法保证不带空格）。
2. **`/SUPPRESSMSGBOXES` 会把「另一个版本已安装，是否继续」自动答「否」** → 退出码 2，
   用户只看到「什么都没发生」。**结论：不要加**。
- 另外查注册表发现本机 2.9.1 + 2.3.0 两个卸载项指向同一目录；UAC 弹窗（consent.exe）出现过，
  说明安装链路本身没问题，失败在参数与 UAC 确认。
- 界面安装改为后台线程 `_InstallThread` 等退出码（`wait=False` 时代什么都看不到）；
  失败弹框给原因并可直接「改用完整安装向导」重试。**实测 2.9.1 静默安装成功（38.5s，码 0）。**
- 顺带发现 `.iss` 的 `[INI] version.txt` 用了 `createkeyifdoesntexist`，key 已存在就不覆盖，
  所以 version.txt 一直停在 2.6.0（主程序不读它，暂未改）。

## 新增「下载测试版」（Actions Artifact）
- 用户要求：也能访问 Actions 页、下载最新测试版。
- 关键事实（实测）：`GET /actions/artifacts` **匿名可读**（能看名称/大小/创建时间/run 号）；
  `GET /actions/artifacts/<id>/zip` **匿名 401 Requires authentication** → 下载必须有 token。
- 新模块 `preview.py`：`list_artifacts` / `newest`（只认 `expired=false`）/ `stamp` /
  `download` / `unpack`。`KIND_NAME='F-HamLog-Preview'`（preview.yml 里 ARTIFACT_NAME）。
- **下载是两跳**：先带 `Authorization: Bearer` 请求 zip（禁止 urllib 自动跳转），拿 302 的签名地址，
  再**不带令牌**去签名地址取流 —— 否则令牌会被 urllib 一路带到 CDN 主机上。
- 校验：GitHub 给了 `digest: sha256:...`，下完整包核对，不符删除并报错。
- 解压：自己检查 zip 成员，`..`/绝对路径直接拒绝。
- 解压目录：`<输出目录>/preview/<YYYYMMDD-HHMM>_run<run id>/`，zip 留在同级。
- GUI：按钮行加「下载测试版」（主按钮右侧）。先匿名列产物 → 无 token 时弹「需要 GitHub token」
  （带「打开 Actions 页」按钮）→ 有 token 弹确认（名称/时间/大小/解压位置）→ 后台下载+解压。
  完成/失败提示框里的「打开目录」「打开 Actions 页」都是 ActionRole，**默认按钮设为「关闭」**。
- 坑：槽里同步 `QMessageBox.exec()` 在 `processEvents` 重入下会“立即返回”，
