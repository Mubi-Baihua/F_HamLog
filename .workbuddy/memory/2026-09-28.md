## 修复：toast 在 Windows 上报 UpdateLayeredWindowIndirect failed
- 根因：给无边框半透明（分层）窗口加 `QGraphicsDropShadowEffect`，阴影把绘制脏矩形扩展到
  窗口负偏移区（`dirty=(207x117 -23,-19)`），Windows 拒绝更新 → 满屏
  `UpdateLayeredWindowIndirect failed ... (参数错误。)`。
- 修复：去掉阴影效果，改用细边框（深浅主题各取半透明白/黑 1px）体现卡片感；同时按用户要求
  缩小尺寸（字体 10pt→9pt、内边距 10/16→6/12，卡片更小更紧凑）。
- 注意：`QRectF` 在 `PySide6.QtCore`，不在 `QtGui`。

- 注意：其余窗口（satellite_window / mutual_window / batch_project 等）的同类提示未改，
  若需统一可后续扩展。
