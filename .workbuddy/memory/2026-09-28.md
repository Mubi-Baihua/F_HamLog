## 超长日志（10000 条）主表格性能优化

用户反馈「处理 10000 条日志时卡顿」。定位到 `project.py` 主表格与 `fhl_rw.py` 落盘三处瓶颈，全部修复并离屏基准验证。

### 根因与优化
1. **逐行真实控件 → 自绘委托**（最大瓶颈）
   - 原 `table_update` 每行 `setCellWidget` 一个 `QWidget+QHBoxLayout+QCheckBox`（第0列）与一个 `QPushButton`（第13列）。
     10000 行 = 2 万个 QWidget，仅构建就 ~18s。
   - 新增 `CheckColumnDelegate` / `MoreButtonDelegate`（模块级类），勾选列与「更多」列改纯绘制 + `editorEvent` 点击回调。
   - 勾选状态权威 = 闭包集合 `_checked_rows`；委托通过 `on_toggle` 回调（`_tbl_check_toggle`）写回，
     **委托不直接改 model**（避免 item 与集合状态分叉）。搜索结果窗传自己的 `_sr_toggle`。
2. **全选/反选/取消选择 O(n) 集合运算**（原实现逐行 `findChild(QCheckBox)`）
   - 全选 3.1s→0.017s；反选 9.2s→0.022s。
3. **`_fill_rows` 批量填充**：填充期间 `setUpdatesEnabled(False)` 冻结刷新、批量 setItem。
   列宽仍按旧实现 14 列**全部显式设宽**（`_TABLE_COL_WIDTHS=[45,80,70,90,90,70,80,90,90,80,80,120,120,80]`），
   **不启用 stretchLastSection、不强制行高**——与 HEAD 版 UI 逐项一致（详见本文件末尾「UI 对齐」节）。
4. **落盘：`fhl_rw.write_fhl_file`** 由 `json.dump(data, f)`（对上万条记录会发起 ~84 万次小 write）改为
   `json.dumps` 到内存字符串后 `f.write(text)` 一次性写入（1.3s→0.06s）。
5. **`save()` 跳过未变更重复写**：`table_update` 每次都会静默调 `save(message=False)`。
   新增 `_last_written={'path','json'}`（本会话最近真正写过的路径+内容），仅当「同路径 + 同内容」才跳过。
   **首次保存必须执行**（磁盘文件可能与内存不同）——否则破坏 `test_recover_save_smoke` 的
   「普通项目打开即自动保存一次」。`esave`（保存并退出）走 `_write_project_file` 无条件落盘。
6. 新增 `_write_project_file(path)` 统一写入并记录快照；`_bk_snapshot(snap=None)` 支持复用已算好的 JSON。
7. 行数 ≥ `_BUSY_CURSOR_THRESHOLD(=2000)` 时重建期间 `setOverrideCursor(Qt.WaitCursor)`（try/finally 保证恢复）。

## 点「更多」保存后表格弹回顶部 —— 修复（用户第 2 条）

用户反馈：**每次点「更多」→ 保存，表格直接跳到第 1 行**，希望回到之前的位置。

### 根因
`project_others.save_changes()` 改完 `file[index]` 后调 `table_update()`，而
`table_update` 每次**新建整个 QTableWidget** 替换旧的 → 新控件滚动条默认 value=0（回到顶部）。

### 修复（project.py `table_update`）
- 重建前记录旧表格 `table.verticalScrollBar().value()`（像素偏移；行高统一，可精确还原）。
- 重建后、`scroll_to_bottom=False` 且 `prev_scroll>0` 时，**用 `QTimer.singleShot(0, ...)` 延迟恢复**
  该偏移：必须等 Qt 按新布局算好视口高度与滚动范围再设，否则会被布局过程重置回顶部。
- `scroll_to_bottom=True` 分支同样改为 `QTimer.singleShot(0, table.scrollToBottom)`
  —— 原来在 `addWidget` 后同步调用会因视口高度未定而**少滚 1 行**（实测 486/487）。
- 行数变少时 `setValue` 会按新最大值自动收敛，无需手动 clamp。
- 新增 `_perf_api['project_others']` 供测试走「真实链路」（打开更多窗→点保存更改按钮）。

### 新增测试

## 修复：toast 在 Windows 上报 UpdateLayeredWindowIndirect failed
- 根因：给无边框半透明（分层）窗口加 `QGraphicsDropShadowEffect`，阴影把绘制脏矩形扩展到
  窗口负偏移区（`dirty=(207x117 -23,-19)`），Windows 拒绝更新 → 满屏
  `UpdateLayeredWindowIndirect failed ... (参数错误。)`。
- 修复：去掉阴影效果，改用细边框（深浅主题各取半透明白/黑 1px）体现卡片感；同时按用户要求
  缩小尺寸（字体 10pt→9pt、内边距 10/16→6/12，卡片更小更紧凑）。
- 注意：`QRectF` 在 `PySide6.QtCore`，不在 `QtGui`。

- 注意：其余窗口（satellite_window / mutual_window / batch_project 等）的同类提示未改，
