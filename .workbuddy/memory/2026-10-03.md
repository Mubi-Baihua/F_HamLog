## 批量记录冻结列：切语言后错位（修复）

- **现象**：冻结批量记录首页（`batch_project.FrozenTableWidget`）切语言后冻结列与主表**错位**。
- **根因**：冻结层 x = `verticalHeader().width()`；切语言时行标签由中文变英文，竖向表头宽度
  76 → 124（差 48px）。旧实现只在 `resizeEvent` 里重算几何 —— **窗口够宽时切语言不触发 resize**，
  x 就停在旧值 → 整列偏移正好一个表头宽度。`__batch_frozen_i18n_probe2.py` 可复现（宽窗 dx=48，窄窗 dx=0）。
- **修复**：新增 `_schedule_frozen_geometry()`，接 `verticalHeader().geometriesChanged` /
  `horizontalHeader().geometriesChanged` / `model().headerDataChanged` 三个信号，
  **延后一轮**（`QTimer.singleShot(0)`）再 `updateFrozenGeometry()` —— 表头文字变化后，竖向表头宽度
  要到本轮布局结束才更新，立刻量拿到的是旧值。合并多次请求只跑一次（`_frozen_geom_pending` 守卫）。
- **验证**：`test/__batch_frozen_i18n_probe2.py` 两种窗口尺寸（1200×790 会 resize / 1900×900 不 resize）下
  中英文 dx 均为 **+0**（对齐）。

## 设置窗口：「语言:」标签不翻（词表键对不上）+「保存更改」加宽

- **现象**：`i18n_zh_en.py` 里写着 `'语言 Language:': '语言 Language:'`，但界面（英文下）这个标签仍是中文。
- **根因**：词表**键必须与源码字符串逐字符一致**；`set.py:202` 是 `QLabel('语言:', ...)`，
  界面上**根本不存在** `语言 Language:` 这个串 → 查表永不命中，原样返回中文。
  且该条 key == value 是**恒等映射**，「命中」了也不会变 —— 属于典型的「改了等于没改」。
- **修复（定稿）**：改成**双语标签** —— `set.py:202` 为 `QLabel('语言 Language:')`，
  词表键同步为 `'语言 Language:': 'Language:'`（中文界面显示源文案「语言 Language:」，
  英文界面查表得「Language:」）。**词表键永远要跟源码原文一致，改词表改不动源码文案。**
- **验证**：`__set_lang_row_smoke.py` **12/12 通过**，实测中文 `标签='语言 Language:'`（宽 144）、
  英文 `标签='Language:'`、`按钮='Save changes'`；中文窗口仍 770×475。
  `__i18n_smoke.py` 9 窗三阶段：**漏翻/未还原 0、横向被裁切 0、竖向被压扁 0**。
  `__i18n_check.py` 的「词表里有、源码里找不到」列表已不含该条。
- **加宽按钮**：`set.py:254` 后加 `sett_button.setMinimumWidth(170)` —— 实测按钮宽 **80 → 170 px**
  （先试 130 仍嫌窄，再放宽；右边缘 x=761 / 窗口 770，同行未越界）。
  **若继续调宽，只改 `set.py:254` 这一行常量**；英文 `Save changes` 自适应，不会截断。
- 注：同步更新了 `test/__set_lang_row_smoke.py` 里的标签查找字面量（`'语言 Language:'`）。

## 词表 `'语言 Language:'` 的值被改回中文（发现并恢复）

- **现象**：`__i18n_smoke.py` 报「漏翻 1 处 text: '语言 Language:'」（英文界面下该标签仍是中文）。
- **根因**：`i18n_zh_en.py` L156 的值变成了 `'语言 Language:'` —— **与键相同（恒等映射）**，
  英文查表得到的还是中文原文。而 10:08 那次改动后实测是 `'Language:'`（说明当时是对的），
  文件 mtime 为 **14:54:05**，落在会话间隙 → 判断是**编辑器里早先打开的旧缓冲被保存覆盖**。
- **处理**：恢复为 `'语言 Language:': 'Language:',`；`__i18n_smoke.py` 回落 **0 漏翻**。
- **教训**：改词表**值**之后必须跑 `__i18n_smoke.py` 看「漏翻」一栏；**key == value 等于没翻**，
  且这种条目会被漏翻检测抓出来。
