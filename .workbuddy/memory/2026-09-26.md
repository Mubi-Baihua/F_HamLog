## 新增：星历数据源可配置（设置窗口）+ 上限 250 + 下载/导入按编号增量更新

用户需求（@scene#15）：
1. 支持设置下载星历数据时的数据源 → 默认内置 Celestrak，用户可手动添加自定义
   下载地址（例：`https://tledata.xanyi.eu.org/tledata/all.txt`）并排序，
   不同数据源冲突时用排序靠前的；
2. 最大卫星数 500 → 250；
3. 从文件导入时不要自动选择；
4. 无论下载还是导入，都只按卫星编号更新；之前存在但本次数据里没有的也要保留。

## 颜色模式改为「以跟随系统的为准」（同日追加）
用户反馈：跟随系统的深色与手动选深色观感有差距。

### 取证（真实桌面，windows11 风格）
| 请求 | Qt 给出的调色板（Window / Base / Button / Highlight / Link） |
|---|---|
| 跟随系统（系统=浅色） | #f3f3f3 / #ffffff / #ffffff / #0067c0 / #003e92 |
| 请求深色 | #1e1e1e / #2d2d2d / #3c3c3c / #0078d4 / #99ebff |
| 请求浅色 | #f3f3f3 / #ffffff / #ffffff / #0067c0 / #003e92 |
→ 差距根源：手动深色被自建 `_DARK_ROLES`（Window #353535）顶掉，而系统深色本来是 #1e1e1e。

### `theme.py` 重构
- 新增 `system_scheme()`（`styleHints().colorScheme()`）、`_want_dark()`（system → 采信系统探测；
  探测不到返回 None）、`_palette_is_dark()`、`_settle()`、`_adopt_platform_palette()`（返回
  `system/platform/fallback`，记到 `_last_source`）、`_install_scheme_listener()`（`colorSchemeChanged`
  → **仅强制模式**重放；`_applying` 防重入）。
- `apply()`：`setPalette(QPalette())` 撤覆盖 → `setColorScheme(方案)` → `_settle` → **平台调色板优先**，
  只有明暗不符时才用 `_DARK_ROLES/_LIGHT_ROLES` 兜底。`_settle` 用 `sendPostedEvents` 而非
  `processEvents`（避免在槽里重入）。
- 自建调色板降级为「平台不认请求时」的兜底（离屏 fusion 即走这条：深色 #353535、浅色采用 fusion #efefef）。

### 关键坑（实测）
- **`app.palette()` 的拷贝不能拿去 `setPalette`**：Qt 视为「颜色没变」直接忽略（用同值**手工构造**的
  QPalette 才生效）→ 曾导致真实平台测试假阴性。要改调色板一律 `QPalette()` 自己造。
- 请求配色方案后 `setPalette` 仍然有效（兜底可用），已用探针确认。
