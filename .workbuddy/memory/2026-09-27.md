## 再续：文件对话框深色【真正的根因】——盖错了调色板

用户第三次复测仍反馈「打开/保存窗口还是有问题／整个窗口还是浅色」。

### 真正的根因（前两轮都没找对）
用探针（`__dlg_probe*.py`，已删）在**真实 windows 平台**下逐层验证，得到三条硬结论：

1. **本机 `QFileDialog` 永远是 Qt 自绘**：即使显式 `setOption(DontUseNativeDialog, False)`，
   `winId()` 类名仍是 `Qt6111QWindowIcon`、toplevel 就是它自己、含 4×QListView/1×QTreeView/
   1×QLineEdit/2×QPushButton。**这个 Qt 6.11 build 根本不产出 Win32 `#32770` 原生对话框**。
   → 所以 **DWM 那条路完全是 no-op**，`DWMWA_USE_IMMERSIVE_DARK_MODE` 不起任何作用
   （之前"假成功"的推论这里得到最终确认：不是"打错 HWND"，而是**压根没有真原生对话框可打**）。
   → 真正起作用的只有**调色板**这一条路。
   - 上轮"用 QListView/子控件多寡判定原生与否"的判断也是**错的**：QListView 是 Qt 自绘对话框
     **自己的**子控件，真原生 IFileDialog 反而没有 Qt 子控件。判定本身无意义，删掉即可。

2. **给 dialog 单独盖 `dark_palette()` 兜底色是错的**（这正是"还是有问题"的直接原因）：
   `_last_source == 'platform'` 时（Win11 平台认 `setColorScheme`），`app` 调色板已是平台标准
   深色 `#1e1e1e`/Base `#2d2d2d`；而我却用 `_DARK_ROLES` 兜底的 `#353535`/`#252525` 单独盖住
   dialog —— **盖掉了平台标准色**，对话框与程序其余部分深浅不一致（观感发灰、像另一个程序）。
   实测对照：
   | 做法 | dialog Window | list Base |
   |---|---|---|
   | 盖 `dark_palette()` 兜底（旧） | `#353535` | `#252525` |
   | 清掉覆盖跟随 app（新） | `#1e1e1e` | `#2d2d2d` |

3. **"重启后才出现"的解释**：`apply_native_dialog_theme` 只在 `_run_dialog`（每次开对话框）里调，
   而 `theme.set_mode`/`apply()` 是 **app 级** `setPalette` → 立刻作用于之后新建的一切控件。
   旧代码给 dialog 盖的是**写死的兜底色**，与实际主题无关，所以"重启"只是恰好重建了控件树，
   并非重启本身有魔力。修复后**无需重启**：会话中 `set_mode('dark')` → 立刻开对话框即为深色
   （探针 5 已验证两个方向：system→dark、dark→light 都即时生效且与 app 色一致）。

### 修法（`theme.py`）
- 新增 `_clear_palette_override(widget)`：对 widget + 全部 `findChildren(QWidget)` 设**默认构造**的
  `QPalette()`（= 取消覆盖 → 继承 app/平台当前调色板）。
- `apply_native_dialog_theme(dialog)` 的 (1) 步由"盖 dark/light_palette()"改为
  **`_clear_palette_override(dialog)`**；(2) 步 DWM 保留（真原生环境靠它，本机无害 no-op）。
- `want is None`（跟随系统）时仍直接返回不干预——此时 app 调色板本身就是系统给的，对话框自然跟随。
- docstring 全部重写，把上面三条硬结论固化下来，防止再退回"盖兜底色"。

### 验证
- `__dark_filedialog_map_smoke.py` 第 2 段加强：新增断言
  `dialog Window 色 == app Window 色`（深浅两态都断言），专门卡住"盖兜底色"这个回归；
  并同时输出 list Base。offscreen（走兜底）`dark=#353535/#252525 light=#efefef/#ffffff`；
  **真实 windows 平台 `dark=#1e1e1e/#2d2d2d light=#f3f3f3/#ffffff`**（即 Win11 标准色），SMOKE_OK。
- 回归全绿：`__theme_mode_smoke` 60/0、`__scheme_system_smoke` 16/0、`__map_smoke` OK、
  `__dark_theme_switch_smoke` OK、`__dark_batch_final_smoke` OK、`test_recover_save_smoke` 27/0、
